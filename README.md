# Hello World 🌎

A collection of **"Hello World" implementations written in different programming languages**.

The purpose of this repository is simple: take one of the most fundamental programming exercises and use it as a way to explore how different languages approach the same basic task.

Although every implementation produces essentially the same result, each language uses its own syntax, structure, conventions, and way of executing a program.

## 🎯 Purpose

"Hello World" is often one of the first programs written when learning a new programming language.

Instead of creating it once, this project takes the concept further by implementing the same basic program across multiple languages.

This makes it possible to observe:

* How different languages define their program entry point.
* How they print or display text.
* Differences in syntax and structure.
* How much code is required for the same task.
* The similarities shared between programming languages.
* The different conventions used by each ecosystem.

## 💻 What Each Example Does

Every implementation has the same fundamental objective:

```text
Hello world
```

The actual syntax varies depending on the language, but the underlying programming concept remains the same.

For example, a language may use a `print` function, `println`, `console.log`, `printf`, or another mechanism to display the message.

## 🧠 What This Project Represents

The simplicity of this project is intentional.

Learning programming is not only about memorizing the syntax of a particular language. It is also about understanding fundamental concepts that can be transferred from one language to another.

Once the underlying concept is understood, learning how a different language expresses that concept becomes much easier.

This repository is therefore both a small collection of examples and a visual reference for comparing programming languages.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/MichaelAcostaDev/helloWorld.git
```

Move into the project:

```bash
cd helloWorld
```

Each language has its own folder containing its corresponding implementation.

To run an example, use the compiler or interpreter appropriate for that language.

For example, a Ruby implementation can be executed with:

```bash
ruby ruby/helloWorld.rb
```

The exact command depends on the language and the file contained in its respective directory.
